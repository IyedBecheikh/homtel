## About

A Windows Forms hotel-management application foundation for a desktop booking and hospitality workflow.

**Status:** Older desktop prototype; the current source is a small WinForms foundation and requires a defined domain model.

## Features

- Open the solution in Visual Studio with .NET Framework 4.7.2 support.
- Build and run the `HOMTEL_APP` project from the IDE.
- The repository does not yet document a command-line build path.
