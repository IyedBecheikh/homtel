# HOMTEL

An early Windows Forms desktop prototype for a hotel-management application.

> Status: the repository currently provides a .NET Framework 4.7.2 application shell and forms. Room, reservation, guest, and staff workflows still need to be defined and implemented.

## Stack

- C# and Windows Forms
- .NET Framework 4.7.2
- Visual Studio solution: `HOMTEL_APP.sln`

## Run locally

Open `HOMTEL_APP.sln` in Visual Studio with .NET Framework 4.7.2 support, select the `HOMTEL_APP` project, then build and run it.

## Next steps

- Define the data model for rooms, reservations, guests, and staff.
- Add persistence and validation.
- Document the real user flows with screenshots once they exist.
